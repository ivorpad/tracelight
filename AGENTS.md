# Agents

To understand, debug or explain what a JavaScript or TypeScript file did, use Tracelight instead of reading the source: `skills/tracelight/SKILL.md` is the one skill, with a mode as its first argument. `ask` answers a question about code in chat from a recording of it running, including hidden failures, what an edit changed and profiles (`references/ask.md`), `debug` pauses a running program and steps it (`references/debug.md`), `explain` walks a person through a run in their editor or the browser page (`references/explain.md`), `show` investigates and hands over a tour or a code-history page whose every value `tracelight history` generated from the run (`references/show.md`).
The command reference is `skills/tracelight/references/tracelight-cli.md` (every verb and flag; `node/test/skill.test.ts` keeps it complete), the page's contract `references/code-history.md`, the debugger's `references/live-debugger.md`, the browser page's `references/browser.md`, the Claude Code band's `references/band.md`.
Start with `tracelight story run.json --file FILE` (the map, one step number per line) and `tracelight step run.json N --into` (land in the callee with its arguments). For a program running now, `tracelight debug FILE --at NAME` starts it and prints the first stop.
Run the CLI as `tracelight ...` (the extension keeps `~/.local/bin/tracelight` pointing at its runtime while `tracelight.agentAccess` is on), or from this checkout as `node node/bin/tracelight.mjs ...` after `npm ci --prefix node`; `--live` instead of `run.json` drives the open VS Code session.
MCP clients get the same commands as tools from `tracelight mcp` (`skills/tracelight/references/mcp.md`).
To show a person a run in a browser and step through it while explaining, start `tracelight web FILE` and drive the page with `tracelight web ctl step over --say "..."` (from a checkout after `npm run build`, `node dist/web/server.js` takes the same arguments; `docs/WEB.md`, `references/browser.md`).
Build, test and quirks for working on the extension itself: `docs/HANDOFF.md`; the runtime's layout: `docs/RUNTIME.md`; wire contract: `docs/PROTOCOL.md`.
